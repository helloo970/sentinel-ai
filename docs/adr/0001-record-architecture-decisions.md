# 1. Record architecture decisions

- Status: accepted
- Date: 2026-10-19

## Context

SENTINEL AI is a long-running portfolio project. Decisions about architecture and
security need to stay traceable for future contributors and reviewers.

## Decision

We record significant decisions as Architecture Decision Records in `docs/adr/`,
numbered sequentially, using the format: context, decision, consequences.

## Consequences

- Every milestone that changes architecture or security adds or updates an ADR.
- Superseded ADRs stay in the repository and are marked as superseded.
